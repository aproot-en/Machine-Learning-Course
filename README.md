# Machine-Learning-Course

This repository contains all course materials for the **Machine Learning** course for **CPE students** in **Semester 1, Academic Year 2026 (2569)**. It includes lecture slides, lab exercises, datasets, source code, assignments, projects, and additional learning resources. 

## Course Contents

- ML-01: Introduction
- ML-02: Data Preprocessing
- ML-03: Regression & Classification
- ML-04: K-Nearest Neighbors (KNN)
- ML-05: Support Vector Machine (SVM)
- ML-06: Neural Networks (NN)
- ML-07: Convolutional Neural Networks (CNN)
- ML-08: Deep Convolutional Neural Networks (DCNN)
- ML-09: Object Detection I
- ML-10: Object Detection II
- ML-11: Machine Learning Applications I
- ML-12: Machine Learning Applications II

# ML-10-Object Detection II

Learn and implement object detection using YOLO with Python and pre-trained models on the COCO dataset. The project covers YOLO architecture, pre-trained weights, COCO classes, image preprocessing, bounding box prediction, confidence scores, class prediction, Intersection over Union (IoU), Non-Maximum Suppression (NMS), object detection, model inference, and visualization of detection results.

# การตรวจสอบและกู้ไฟล์หลังลบโฟลเดอร์

ตรวจสอบเมื่อ 10 พฤศจิกายน 2026

## ไฟล์ที่สร้างหรือกู้กลับมา

- `config.yaml`: สร้างค่าตั้งต้นจากโค้ดและการตั้งค่าที่เคยใช้ พร้อมแก้พาธ ML ไปที่ `exam_cnn`
- `alembic.ini`: สร้างการตั้งค่า migration สำหรับ `exam_migrations`
- `.gitignore`: คืนกฎละเว้น environment, ข้อมูลฝึก, โมเดล, ฐานข้อมูล และภาพอัปโหลด
- `.venv`: สร้าง environment ของโปรเจกต์กลับมาและติดตั้งแพ็กเกจที่โค้ดใช้งาน
- `exam_input_files/CCF_000001.png` ถึง `CCF_000005.png`: กู้ภาพ 819 × 1161 พิกเซลจากไฟล์อัปโหลดที่ยังอยู่
- `exam_input_files/test-data-image-org/CCF_000001.png` ถึง `CCF_000005.png`: กู้ภาพ 850 × 1200 พิกเซลจากไฟล์อัปโหลดที่ยังอยู่

ภาพที่กู้ทั้ง 10 ไฟล์เป็นการคัดลอกข้อมูลเดิมโดยไม่แก้ไขภาพ ตรวจ SHA-256 ให้ตรงกับสำเนาต้นทางแล้ว รายละเอียดอยู่ใน `exam_reports/recovery_manifest.json`

## ข้อมูลที่ยังไม่พบต้นฉบับ

- **ฐานข้อมูลเดิม `aegs.db`**: ไม่พบไฟล์สำรองใน workspace หรือสำเนาภายใน `D:\Code_ML` และไม่พบรายการที่ตรงกับโปรเจกต์ในถังรีไซเคิล การเริ่มระบบสร้างฐานข้อมูลว่างพร้อม schema ได้ แต่ไม่สามารถคืนชื่อข้อสอบ เฉลย คะแนน การแก้คำตอบ และประวัติเดิมจากภาพอัปโหลดเพียงอย่างเดียว
- **ภาพแบบฟอร์มเปล่า `ORG-Test-image.png`**: ไม่พบสำเนาต้นฉบับ ภาพ overlay ใน `exam_reports/debug` เป็นภาพที่มีกรอบ debug จึงไม่ได้นำมาสวมแทนต้นฉบับ

ตัวอ่าน OMR ใช้เทมเพลต JSON ที่ยังอยู่ใน `exam_src/vision/templates` จึงไม่ต้องใช้ภาพเปล่าในการตรวจข้อสอบตามปกติ แต่การสร้างเทมเพลตใหม่และการทดสอบภาพสังเคราะห์ต้องมีภาพเปล่าต้นฉบับ

ภาพอัปโหลดที่ยังอยู่ใน `exam_reports/uploads` ยังคงเก็บไว้ การสร้าง schema ใหม่ไม่ได้เชื่อมไฟล์เหล่านี้กลับเป็นข้อสอบโดยอัตโนมัติ เพราะไม่ทราบเฉลยและข้อมูลข้อสอบเดิมที่ถูกลบ

## การแยกส่วน ML

ย้ายโค้ด `data`, `models`, `training` จาก `exam_src` มาที่ `exam_cnn` พร้อมชุดข้อมูลใน `exam_cnn/datasets`, โมเดลทั้ง 4 รูปแบบใน `exam_cnn/models_export`, รายงานการฝึกใน `exam_cnn/reports` และเอกสาร ML ใน `exam_cnn/docs`

เว็บเรียก `exam_cnn.models.inference.LetterInferenceWrapper` คำสั่งเตรียมข้อมูล ฝึก ประเมิน และส่งออกใช้ `python -m exam_cnn...` จากโฟลเดอร์หลัก รายงานฝึกใช้ `paths.ml_reports` ส่วนภาพอัปโหลดและรายงาน OMR ใช้ `exam_reports` ตามเดิม

ชุดติดตั้งแยก dependency ของ ML ไว้ใน `exam_cnn/requirements.txt` ใช้ PyTorch และ TensorBoard 2.20.0 โดยไม่ต้องใช้ TensorFlow ส่วน dependency ของเว็บและการทดสอบอยู่ใน `requirements.txt`

## ผลตรวจสอบหลังแก้ไข

- ชุดทดสอบรวมเว็บ OMR และ CNN: **59 ผ่าน, 1 ข้าม** รายการที่ข้ามต้องใช้ภาพเปล่า `ORG-Test-image.png` ที่ยังไม่พบต้นฉบับ
- ตรวจการเริ่มระบบ หน้าเว็บ ไฟล์ CSS/โลโก้ และเอกสาร API ผ่าน
- ทดสอบสร้างข้อสอบ กรอกเฉลย อัปโหลดภาพ ตรวจ OMR แบบ background job เปิดภาพต้นฉบับ คำนวณคะแนน และส่งออก Excel 4 ชีตผ่าน โดยใช้ฐานข้อมูลทดสอบแยก
- ทดสอบ `/api/predict/single` ซึ่งโหลดโมเดลจาก `exam_cnn` ผ่าน
- checkpoint, TorchScript, quantized TorchScript และ ONNX โหลดจากตำแหน่งใหม่ได้ และให้คลาสตรงกันบนข้อมูลทดสอบจริง 8 ภาพ
- ทดสอบ data loader และหนึ่งขั้นตอน forward/backward/optimizer บน CUDA พร้อมเขียน TensorBoard log ผ่าน โดยไม่เขียนทับ checkpoint เดิม
- `.venv` ใช้ `include-system-site-packages = false`; `pip check` รายงานว่าไม่มี dependency ที่ขาดหรือขัดแย้ง
- บันทึกแพ็กเกจของ environment ที่ตรวจสอบแล้วไว้ใน `requirements-full-freeze.txt`
- ตรวจ syntax ของโค้ดและลิงก์ README รวมถึงพาธใน config แล้ว

สร้าง `aegs.db` ใหม่พร้อมโครงสร้างล่าสุดเพื่อให้เว็บเริ่มทำงานได้ ฐานข้อมูลนี้ยังไม่มีข้อมูลข้อสอบเดิม การทดสอบ API ไม่ได้เพิ่มข้อสอบตัวอย่างลงฐานข้อมูลใช้งานจริง

ตัวรันทดสอบในสภาพแวดล้อมที่จำกัดสิทธิ์ใช้โฟลเดอร์ชั่วคราวภายใน workspace แทนโฟลเดอร์ TEMP ปริยายของ pytest
